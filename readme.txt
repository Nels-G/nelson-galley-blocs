Styles de blocs, composants et modèles d'articles pour une mise en page éditoriale soignée dans l'éditeur WordPress.

== Description ==

* 26 styles de blocs : encadrés, étapes, coches, frise, comparatif, FAQ, terminal, cadres navigateur et téléphone…
* 16 composants prêts à insérer et 4 modèles d'articles
* Palette de couleurs à la charte dans l'éditeur
* Bouton « Copier » sur les blocs de code
* Mises à jour depuis les releases GitHub

== Installation ==

1. Extensions › Ajouter › Téléverser une extension, puis choisir nelson-galley-blocs.zip.
2. Activer l'extension.
3. Dans l'éditeur : panneau « Styles » de chaque bloc, et onglet « Compositions ».
